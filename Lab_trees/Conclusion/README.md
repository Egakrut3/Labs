# Вывод по деревьям

Этот пункт заполняется после запуска benchmark-сценариев во всех ветках заданий.

## Как получить графики

Для каждой структуры выполнить из корня репозитория:

```sh
make -C Lab_trees bench TREE=<tree> DATA_TYPE=random OPERATION=all
make -C Lab_trees graph TREE=<tree> DATA_TYPE=random OPERATION=all
```

Для специальных отсортированных тестов:

```sh
make -C Lab_trees bench TREE=Naive_tree DATA_TYPE=sorted OPERATION=all
make -C Lab_trees graph TREE=Naive_tree DATA_TYPE=sorted OPERATION=all

make -C Lab_trees bench TREE=AVL_tree DATA_TYPE=sorted OPERATION=all
make -C Lab_trees graph TREE=AVL_tree DATA_TYPE=sorted OPERATION=all
```

`hyperfine` должен быть доступен в `PATH`.

## Ожидаемое сравнение

Наивное дерево поиска показывает хорошее время на случайной последовательности, но резко деградирует на отсортированной последовательности, потому что дерево превращается в цепочку. Поэтому sorted-тест длины `10000` должен быть заметно хуже random-теста на один элемент операции.

AVL-дерево поддерживает балансировку по высоте, поэтому random-тесты `100000...1000000` должны давать близкий к `O(n log n)` рост. На отсортированной последовательности длины `1000000` деградации до цепочки быть не должно.

Декартово дерево зависит от распределения приоритетов. При детерминированном псевдослучайном приоритете ожидается поведение, близкое к сбалансированному дереву, с небольшими колебаниями на графиках.

Splay-дерево имеет амортизированную сложность `O(log n)`. На тестах без локальности обращений оно обычно уступает строгим балансирующим деревьям из-за дополнительных поворотов, но не должно деградировать как наивное дерево.

КЧ дерево и AVL-дерево должны быть близки по асимптотике. КЧ дерево обычно делает меньше строгой балансировки, поэтому на вставках может быть конкурентным, а AVL может выигрывать на поискообразных сценариях за счёт более строгой высоты.

B-дерево с `t = 64` хранит много ключей в одном узле и имеет малую высоту. В in-memory тесте оно может тратить время на сдвиги внутри узла, но рост должен быть устойчивым и близким к `O(n log n)`.

Skip-list является вероятностной структурой. Ожидается плавный рост, близкий к `O(n log n)`, но с большим постоянным множителем и большей вариативностью, чем у AVL/КЧ дерева.
